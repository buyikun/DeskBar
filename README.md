# DeskBar (v1.0)

> Windows 11 现代轻量任务栏透明、多浮岛美化与系统级扩展增强工具。

---

## 🌟 核心特性

- 🏝️ **任务栏多浮岛形态 (Multi-Island Taskbar)**：
  - 自动为 Windows 11 任务栏构建独立视觉岛屿（中央应用区、系统托盘区）。
  - 支持 **原味自然亚克力 (Natural Acrylic)**、深色亚克力、全透明 (Clear) 等多种风格切换。
  - 像素级 1px 细微圆角描边，自适应深浅色系统主题。

- 🎵 **任务栏音乐胶囊 (Music Capsule)**：
  - 实时集成 Windows GSMTC 全局媒体控制接口（QQ音乐、网易云音乐、酷狗等）。
  - 紧密吸附于右下角托盘左侧，展示当前曲目、歌手、专辑封面，并集成上一曲/暂停/下一曲交互。
  - **即切即用轻量化架构**：GSMTC 本地流优先 + 官方实时解析兜底，无本地缓存膨胀，无额外磁盘 I/O。

- 📊 **左侧系统监控浮岛 (System Monitor Capsule)**：
  - 常驻显示 CPU、GPU、内存使用率及上下行网速（上行 ↑ / 下行 ↓ 独立指示条与数值）。
  - 低功耗高性能采集，全生命周期超低资源消耗。

- ⚙️ **现代设置中心 (Modern Settings UI)**：
  - 采用现代双栏卡片设计，支持自动日夜主题切换、任务栏风格自选、浮岛开关及故障自愈诊断。

- 🖱️ **桌面图标双击显隐**：
  - 支持双击空白桌面快速切换桌面图标显隐，享受无干扰壁纸体验。

---

## 🚀 运行与构建

- 依赖环境：`.NET 8.0 Windows Desktop Runtime`
- 架构：`win-x64`

### 构建发布
```powershell
./build.ps1
./publish.ps1
```
产物将输出至 `out_publish/`。
