# DeskBar (v2.0.0)

> Windows 11 现代轻量任务栏透明、多浮岛美化与系统级扩展增强工具。

---

## 🌟 核心特性

- 🏝️ **任务栏多浮岛形态 (Multi-Island Taskbar)**：
  - 自动为 Windows 11 任务栏构建独立视觉岛屿（中央应用区、系统托盘区）。
  - 支持 **原味自然亚克力 (Natural Acrylic)**、深色亚克力、全透明 (Clear) 等多种风格切换。
  - 像素级 1px 细微圆角描边，自适应深浅色系统主题。

- 🎵 **任务栏音乐胶囊 (Music Capsule)**：
  - 实时集成 Windows GSMTC 全局媒体控制接口（QQ音乐、网易云音乐、酷狗等）。
  - 紧密吸附于右下角托盘左侧，展示当前曲目、歌手、专辑封面，并集成上一曲/暂停/下一曲交互。
  - **即切即用轻量化架构**：GSMTC 本地流优先 + 官方实时解析兜底，无本地缓存膨胀，无额外磁盘 I/O。

- 📊 **左侧系统监控浮岛 (System Monitor Capsule)**：
  - 常驻显示 CPU、GPU、内存使用率及上下行网速（上行 ↑ / 下行 ↓ 独立指示条与数值）。
  - 低功耗高性能采集，全生命周期超低资源消耗。

- ⚙️ **现代设置中心 (Modern Settings UI)**：
  - 采用现代双栏卡片设计，支持自动日夜主题切换、任务栏风格自选、浮岛开关及故障自愈诊断。

- 🖱️ **桌面图标双击显隐**：
  - 支持双击空白桌面快速切换桌面图标显隐，享受无干扰壁纸体验。

## 🆕 v2.0.0 重点升级

### 逐字歌词引擎
- 新增 **字级时间戳** 渲染：把每个词的时长按字数均分到单字，中英文混排也能按真实演唱速度逐字点亮。
- 支持 **QRC / KRC / YRC / LRC** 多格式解析，逐字与逐行两种回退路径。
- 歌词跟随曲目自动切换，无歌词时优雅回落显示歌手。

### 媒体来源智能路由
- 新增 `MediaSourceRouter`：对 GSMTC 候选源 **过滤 + 打分排序**，不再「取第一个能用的」。
- 排除抖音、雷电模拟器等会抢占会话的宿主进程，以及 `svchost` / `audiodg` / `nvcontainer` 等系统级伪来源。
- 专用播放器 > 浏览器网页媒体 > 其它，优先级明确。
- 支持 **固定播放器来源**（`MusicCapsulePinnedSource`），重启后不再丢失手动选择。

### 播放器白名单鲁棒性
- 白名单同时识别 **全角 / 半角** 逗号、顿号、分号与换行，不再因中文输入法导致整串失效。
- 匹配时既比对 `appId`，也比对菜单中显示的 **中文友好名**。

### 昼夜方案完全可配
- 白天 / 夜晚 **各自独立** 配置界面深浅色与材质色调（`DayThemeLight` / `NightThemeLight` / `DayAcrylicTone` / `NightAcrylicTone`）。
- 移除写死的 `auto` 别名，消除「系统深浅色 ← DeskBar 改写 ← auto 读取」的环路。
- 新增 `AutoTimeApplySystemTheme` 开关：自动切换时可选择只影响 DeskBar 自身，不写注册表、不广播 `WM_SETTINGCHANGE`。

### 统一视觉令牌
- 新增 `Themes/Tokens.xaml`（字号 / 圆角 / 字体）与 `Themes/MenuStyles.xaml`（右键菜单柔雾 / 黑丝配色）。
- 设置窗、右键菜单、监控详情窗收敛到同一套圆角与字号阶梯，消除「两套软件拼起来」的观感。
- 颜色统一由 `TonePalette.cs` 下发，不再散落在各处 XAML。

### 日志与稳定性
- `Log` 增加 **防膨胀机制**：单文件 3MB 上限、目录总量 10MB 上限、历史日志保留 3 天、每 6 小时巡检。
- `StartupService` 增加 `reg.exe` 兜底通道，托管注册表 API 被拒时自启开关仍可用。
- 移除「管理员权限才能接管任务栏外观」的历史误判功能与文案。

## 🚀 运行与构建

- 依赖环境：`.NET 8.0 Windows Desktop Runtime`
- 架构：`win-x64`

### 构建发布
```powershell
./build.ps1
./publish.ps1
```
产物将输出至 `out_publish/`。
