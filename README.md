# DeskBar

> Windows 11 任务栏美化与增强工具。轻量、常驻、无感。

DeskBar 用浮岛式的设计重塑 Windows 11 任务栏：把中央应用区和系统托盘区框成独立岛屿，在左右两端挂上系统监控和音乐胶囊，让任务栏从一条色带变成真正融入壁纸的界面层。

## 功能

- **多浮岛任务栏** — 中央应用区与托盘区独立描边成岛，支持亚克力、毛玻璃、全透明三种融合模式，1px 圆角描边跟随系统深浅色。
- **系统监控浮岛** — 常驻显示 CPU / GPU / 内存占用与上下行网速，点击可展开 Top5 进程详情。
- **音乐胶囊** — 接入 Windows GSMTC 全局媒体接口，显示封面、曲名、歌手与逐字滚动歌词，支持上一曲 / 暂停 / 下一曲。
- **设置中心** — 双栏卡片布局，可自选材质色调、配置白天与夜晚各自的配色方案，支持按时段自动切换。
- **桌面图标显隐** — 双击桌面空白处快速隐藏 / 显示图标。

## 运行环境

- Windows 11
- .NET 8.0 Windows Desktop Runtime
- 架构：win-x64

## 构建

```powershell
./build.ps1
./publish.ps1
```

产物输出至 `out_publish/`，运行其中的 `DeskBar.exe` 即可。
